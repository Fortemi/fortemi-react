# fortemi-react v2026.7.0

fortemi-react v2026.7.0 expands Fortemi's AIWG static index and bridge-search
contracts so AIWG discovery, graph traversal, exported embeddings, and
semantic/hybrid bridge search can share the browser-first `@fortemi/core`
surface.

## Highlights

- **Extensible AIWG record types (#213):** project-specific record types such as
  `aiwg.skill`, `aiwg.command`, `aiwg.rule`, `aiwg.requirement`, and
  `research.ref` now validate and filter directly without collapsing into
  `aiwg.artifact`.
- **AIWG discovery ranking (#214):** opt-in `aiwg-discovery` ranking supports
  hyphen/space normalization, stopword-stripped verbose queries,
  trigger/capability weighting, fallback matching, and match reasons for UI
  debugging.
- **Chunked relationship traversal (#215):** full and chunked AIWG index
  controllers can traverse relationships by direction and type, compose neighbor
  sets, and project community graphs without loading the full export.
- **Static embedding sidecars (#216):** `aiwg.fortemi.embedding.set.v1` records
  model, dimension, granularity, source record, and input-hash metadata so static
  semantic/hybrid search and duplicate reports can run with host-provided query
  embeddings.
- **Bridge semantic/hybrid search (#217):** the bridge search tool now accepts
  `text`, `semantic`, `hybrid`, and `auto` modes. Forced semantic/hybrid calls
  require a `query_embedding`; `auto` falls back to text when no embedding is
  supplied.
- **Documentation sync:** API reference, integration snippets, deployment CI
  wording, release indexes, and runtime version constants were refreshed.

## Compatibility

This is an additive release. Existing `2026.6.9` consumers do not need archive
schema migrations or source changes. Static AIWG consumers can continue using
the existing v1 record shape and opt into discovery ranking, relationship
traversal, and embedding sidecars when those artifacts are present.
