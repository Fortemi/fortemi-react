# fortemi-react v2026.6.1

fortemi-react v2026.6.1 is the bridge configuration, worker-mode, and scalable shard release. It keeps the browser-first archive path intact while adding provider presets for browser-local ML and OpenAI-compatible services, UI-safe PGlite worker execution, chunked shard operations, and graph review of AIWG exports.

## Highlights

- Added bridge-safe provider configuration in the standalone app with preloaded browser-local, OpenAI, OpenRouter, Ollama, LM Studio, Jan, llama.cpp, and vLLM options.
- Required secure browser or machine-backed storage before persisting API keys; providers that need keys stay disabled when secure storage is unavailable.
- Seeded the standalone app with the repository `/docs` corpus so the default UX can search and review project documentation after initialization.
- Added `FortemiProvider` worker execution mode for keeping PGlite startup and heavy archive operations off the main UI thread.
- Added chunked Knowledge Shard import with progress callbacks and event-loop yielding.
- Added set-scoped Knowledge Shard export plus lazy/paged vector handling for large embedding archives.
- Added `GraphView` and AIWG index graph projection for relationship review surfaces.

## Published Packages

- `@fortemi/core@2026.6.1`
- `@fortemi/react@2026.6.1`

## Compatibility

Existing `2026.6.0` consumers can upgrade without source changes. The new provider configuration, `FortemiProvider` worker props, shard options, AIWG graph projection, and `GraphView` export are additive. No archive schema migration is included in this release.

## Verification

Before cutting `v2026.6.1`, run the repository checks on the release-prep commit and wait for CI to pass:

```bash
pnpm typecheck
pnpm lint
pnpm test:core
pnpm test:e2e
pnpm build
```

Cut the release tag with the project release key only:

```bash
tools/release/cut-tag.sh 2026.6.1
git push origin main --tags
git push github main --tags
```
