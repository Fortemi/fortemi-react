# fortemi-react v2026.6.6

A documentation-only maintenance release. The three published packages are unchanged in content from v2026.6.5 — this release ships a docs fix and moves the version line forward in lockstep.

## Changes

- **Docs — getting-started Next Steps links (#193):** the five "Next Steps" links in `docs/getting-started.md` pointed at standalone pages that were never created (`hooks.md`, `capabilities.md`, `archives.md`, `job-queue.md`, `api-types.md`), producing five broken-link warnings in the docsite build. Each now points at the corresponding section of `api-reference.md` — Hooks, Capability Manager, Migrations and Archive, Job Queue, and Types. The docsite build reports zero broken links.

## Published Packages

- `@fortemi/core@2026.6.6`
- `@fortemi/graph@2026.6.6`
- `@fortemi/react@2026.6.6`

## Compatibility

Drop-in for `2026.6.5`. The published packages are identical in content to `2026.6.5` apart from the version number; there are no source, API, or behavior changes. Only repository documentation changed.
