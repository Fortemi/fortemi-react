# fortemi-react v2026.6.0

fortemi-react v2026.6.0 is the June integration and job-queue reliability release. It adds the AIWG Fortemi index import/review surface, improves capability-gated job behavior for search-only deployments, and includes release workflow fixes for internal package publishing and manual publish reruns.

## Highlights

- Added AIWG Fortemi index parsing, validation, and review-decision export helpers for sanitized CRM/task exports.
- Added React `useAiwgIndex()` support and documentation for host applications that ingest AIWG index data.
- Deferred jobs whose `required_capability` is not ready before handler dispatch, keeping them pending with a clear missing-capability message.
- Added `job.blocked` and `capability.required` events so hosts can prompt users to enable or configure missing capabilities.
- Refreshed job queue UI state when jobs are blocked by unavailable capabilities.
- Fixed the Gitea package publishing workflow to use the internal Gitea publish token.
- Passed the selected release tag into publish verification so manual publish reruns validate the intended signed tag.

## Published Packages

- `@fortemi/core@2026.6.0`
- `@fortemi/react@2026.6.0`

## Compatibility

Existing `2026.5.4` consumers can upgrade without source changes. The AIWG index APIs and React hook are additive. No archive schema migration is included in this release. Capability-gated jobs that previously failed when an optional capability was absent now remain pending until the capability becomes ready.

## Verification

Before cutting `v2026.6.0`, run the repository checks on the release-prep commit and wait for CI to pass:

```bash
pnpm typecheck
pnpm lint
pnpm test:core
pnpm test:e2e
pnpm build
```

Cut the release tag with the project release key only:

```bash
tools/release/cut-tag.sh 2026.6.0 -m "v2026.6.0"
git push origin main --tags
git push github main --tags
```
