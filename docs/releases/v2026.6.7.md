# fortemi-react v2026.6.7

fortemi-react v2026.6.7 completes the SKOS and W3C PROV surfaces across the static-shard, PGlite, and remote-server backend tiers. It also syncs the documentation site to the current API surface.

## Highlights

- **Shard reader SKOS/PROV parity:** `openShard()` readers now expose `relationsOf(conceptId)` and `provenanceOf(id)`, and `getNoteFull(id)` can include links, SKOS concepts, and provenance without importing a shard into PGlite.
- **Metadata-complete `DataBackend`:** readable backends can expose `linksOf`, `conceptsOf`, and `provenanceOf` through the uniform backend seam. PGlite, shard, and remote-server adapters map their native records into the same backend-neutral shapes.
- **First-class SKOS and provenance writes:** `SkosRepository` can attach/detach concepts to notes and read concepts for a note; `ProvenanceRepository` can record and query W3C PROV edges.
- **Remote server tier:** `createRemoteBackend(config)` proxies the Fortemi server over HTTP with read/write/merge/multi-user capabilities and `semantic: 'server'`. React adds `useRemote(config)`.
- **Documentation sync:** API reference, package README, docsite config, and release navigation now reflect the current 30 exported React hooks and backend surfaces.

Existing `2026.6.6` consumers upgrade without source changes. The new SKOS, provenance, and remote-backend APIs are additive. Existing PGlite, shard import/export, graph, and capability paths remain compatible.
