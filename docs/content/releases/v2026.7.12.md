# fortemi-react v2026.7.12

fortemi-react v2026.7.12 restores the small, vendorable static AIWG index
boundary while keeping Knowledge Shard conversion available through an explicit
build-oriented entry point.

## Highlights

- **Dependency-free static index (#317):** `@fortemi/core/aiwg-index` has zero
  runtime imports and a package-enforced raw size ceiling of 50 KB. Its current
  minified artifact is 40,598 bytes.
- **Explicit shard conversion:** AIWG-to-Knowledge-Shard conversion now lives at
  `@fortemi/core/aiwg-index-shard`, preventing shard and persistence code from
  entering static documentation and search bundles.
- **Top-level compatibility:** full-runtime consumers may continue importing
  conversion helpers from `@fortemi/core`.

## Published Packages

- `@fortemi/core@2026.7.12`
- `@fortemi/graph@2026.7.12`
- `@fortemi/react@2026.7.12`

## Compatibility

Consumers that imported a converter directly from `@fortemi/core/aiwg-index`
must switch that import to `@fortemi/core/aiwg-index-shard`. Static index
validation, query, chunking, embedding, projection, and review APIs remain on
the original subpath.

Knowledge Shard contract revision 19, schema 1.2.0, and profile semantics are
unchanged. Conversion continues to produce the `core-v1` profile. This release
does not claim `full-v1` browser persistence or RecordStore parity beyond the
separately advertised `record-v1` profile.
