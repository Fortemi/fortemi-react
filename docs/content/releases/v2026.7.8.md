# fortemi-react v2026.7.8

fortemi-react v2026.7.8 makes PGlite fully optional: the canonical record tier
is now writable end-to-end — notes, tags, links, collections, attachments, and
Knowledge Shard import/export all work with zero PGlite, completing the
single-Bytecask-substrate storage architecture (#322, #323).

## Highlights

- **Writable record-tier backend (#323):** `createRecordBackend` serves the
  canonical RecordStore through the backend seam with instant startup and
  read+write+merge capabilities. The full manage-note action surface (update,
  delete, restore, archive, unarchive, star, unstar) runs through the same
  Zod-validated input as the PGlite tool. Capability boundaries are reported
  honestly: search is a bounded unranked scan, and SKOS/provenance methods are
  absent rather than silently emulated.
- **DB-free Knowledge Shard round-trip (#323):** `exportShardFromRecords` and
  `importShardToRecords` speak the standard `.shard` format against canonical
  records. Attachment byte sidecars hydrate through the Bytecask BlobStore;
  missing bytes stay recoverable reference-only; the ADR-014 signed-manifest
  policy runs verify-before-persist; unsupported components (embeddings, SKOS,
  provenance, templates, graphs) skip with explicit warnings. A record-exported
  shard imports into PGlite and vice versa — format parity holds across tiers.
- **Projection rebuild parity (#322):** `projectRecords` projects the complete
  canonical state (note tier + attachment tier) into PGlite idempotently,
  reconciles hard-removed rows, and supports drop + rebuild with row-for-row
  parity. Canonical records and Bytecask bytes are never modified by
  projection lifecycle — PGlite is a derived, rebuildable acceleration layer.

## Compatibility

This release is additive. Existing PGlite-backed flows, shard formats, and
React APIs are unchanged. Shards exported by either tier import into both
tiers; components the canonical tier cannot persist are skipped with explicit
warnings on DB-free import and preserved when importing into PGlite.
