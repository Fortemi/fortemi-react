# fortemi-react v2026.9.3

This corrective release fixes a scoped export defect in the React PGlite
`2.0.0/full-v1` producer. Live full-v1 export now preserves caller tag,
collection, and embedding-set filters instead of silently broadening archives
with out-of-scope data.

## Packages

- `@fortemi/core@2026.9.3`
- `@fortemi/graph@2026.9.3`
- `@fortemi/react@2026.9.3`

## Verification and compatibility

The release keeps the Fortemi authority commit and historical full-v1 fixture
archive identity unchanged. Executable receipt bindings were updated for the
React PGlite implementation, presence receipt, cross-repository receipt, and
advertisement receipt.

Regression coverage verifies tag-scoped content, history, provenance, blob
sidecars, and clean import; collection-scoped history and link exclusion;
embedding-set component/member exclusion; and rejection of scoped exports from
persisted full-v1 snapshots.

The claim remains profile-scoped to React PGlite `2.0.0/full-v1`. This release
does not change the suite-level NO-GO audit and does not establish unqualified
parity, complete backup, or portability.
