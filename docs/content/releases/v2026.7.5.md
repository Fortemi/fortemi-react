# fortemi-react v2026.7.5

fortemi-react v2026.7.5 completes the examples program and tightens the graph
package surface so browser, graph-only, and vendored-schema consumers can build
without pulling in unused database or renderer code.

## Highlights

- **Examples program (#315):** adds the complete examples suite across browser,
  graph, React, and integration workflows. The examples now cover the core
  archive APIs, graph snapshot/render helpers, React bindings, and standalone
  usage patterns expected by downstream app teams.
- **Graph-only package fix (#318):** moves the `GraphController` runtime export
  to `@fortemi/graph/controller` so `@fortemi/graph` can stay free of the
  controller's transitive implementation weight. The React hook imports the
  controller through that subpath internally.
- **Vendored AIWG index schema fix (#317):** exposes the schema authority from
  `@fortemi/core/aiwg-index-schema`, letting vendored consumers validate index
  data without depending on unrelated core barrels.
- **PGlite-free examples:** graph-only and renderer examples no longer need core
  stubs or PGlite WASM/data assets. Consumers that only render graph snapshots
  can keep the database path out of their bundles.
- **Docs:** updates API and integration references to the `2026.7.5` package
  line and publishes these release notes in the docs manifest.

## Published Packages

- `@fortemi/core@2026.7.5`

## Compatibility

Mostly additive. The package versions remain lockstep and existing archive,
shard, snapshot, and React APIs continue to work. Consumers importing the
`GraphController` value from the root `@fortemi/graph` barrel should migrate to
`@fortemi/graph/controller`; type-only root imports remain available where they
are part of the public graph surface. React consumers do not need code changes.
