# fortemi-react v2026.5.4

fortemi-react v2026.5.4 is the graph and embedding release. It introduces virtual embedding-set selectors, precomputed similarity graph persistence, dynamic and user-authored communities, Knowledge Shard graph/community round-tripping, and React hooks for graph-source controller workflows. It also finalizes the split publish path where Gitea keeps the internal registry current and the GitHub mirror performs the npmjs.org provenance publish with `NPMJS_TOKEN`.

## Highlights

- Added virtual embedding-set definitions and selector resolution for default, explicit embedding-set, criteria, set-operation, fallback, latest-compatible, and snapshot sources.
- Added graph/community artifact persistence for graph sources, graph edges, community sets, communities, and assignments.
- Added cached similarity graph loading with freshness state, stale marking, live recompute, and cache-only behavior.
- Added dynamic community previews, saved dynamic snapshots, user-authored communities, and rerun support.
- Added React hooks: `useEmbeddingSets()`, `useSimilarityGraph()`, `useCommunities()`, and `useGraphController()`.
- Added Knowledge Shard export/import support for embedding virtual definitions and graph/community derived artifacts.
- Updated release infrastructure so Gitea publishes internal packages and GitHub publishes public npmjs.org packages with provenance from signed release tags.

## Published Packages

- `@fortemi/core@2026.5.4`
- `@fortemi/react@2026.5.4`

## Compatibility

Existing `2026.5.3` consumers can upgrade without source changes. Archives receive migrations `0007_virtual_embedding_sets` and `0008_graph_community_artifacts` on open. New graph/community APIs are additive, and existing search, note, shard, and capability hooks remain compatible.

## Verification

Before cutting `v2026.5.4`, run the repository checks on the release-prep commit and wait for CI to pass:

```bash
pnpm typecheck
pnpm lint
pnpm test:core
pnpm test:e2e
pnpm build
```

Cut the release tag with the project release key only:

```bash
tools/release/cut-tag.sh 2026.5.4 -m "v2026.5.4"
git push origin main --tags
git push github main --tags
```
