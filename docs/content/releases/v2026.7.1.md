# fortemi-react v2026.7.1

fortemi-react v2026.7.1 updates the AIWG static index contract so Fortemi can
consume AIWG's v2 all-domain export fixtures directly through
`@fortemi/core/aiwg-index`.

## Highlights

- **AIWG export v2 compatibility (#219):** `@fortemi/core/aiwg-index` now
  accepts both `aiwg.fortemi.index.export.v1` and
  `aiwg.fortemi.index.export.v2` envelopes, plus v1 and v2 record schema
  versions.
- **V2 projection fields (#219):** AIWG records can carry `search`, `chunks`,
  `embeddings`, source origin/checksum/update metadata, `privacy.locality`, and
  compatibility metadata while keeping v1 fixtures valid.
- **Relationship traversal fields (#220):** relationship edges preserve
  `target_path` and AIWG relationship `direction`, and traversal helpers can
  filter by relationship direction separately from graph orientation.
- **Chunked traversal parity (#220):** focused fixtures cover dependency,
  citation/profile, KB, and memory graph traversal across whole and chunked
  static indexes.
- **Release metadata:** package versions, runtime constants, API docs, and the
  release index were refreshed for `2026.7.1`.

## Published Packages

- `@fortemi/core@2026.7.1`
- `@fortemi/graph@2026.7.1`
- `@fortemi/react@2026.7.1`

## Compatibility

This is an additive release. Existing v1 AIWG static index exports remain
valid. Hosts can adopt the v2 fields incrementally without replacing PGlite,
Knowledge Shards, or existing graph/community artifact ownership.
