# fortemi-react v2026.7.6

fortemi-react v2026.7.6 adds the canonical portable transport between AIWG v2
index exports, browser-local Fortemi archives, and Fortemi servers.

## Highlights

- **Lossless AIWG conversion:** `@fortemi/core/aiwg-index` now exports
  `aiwgFortemiIndexToKnowledgeShard` and
  `aiwgFortemiIndexFromKnowledgeShard`.
- **Deterministic identities:** AIWG record and relationship identifiers map to
  stable UUIDs, preserving native note/link references across imports.
- **Complete source retention:** every shard note contains the complete original
  AIWG v2 envelope and record metadata, including privacy, source checksums,
  chunks, relationships, SKOS, and provenance fields.
- **Portable common profile:** default output declares notes, tags, and links so
  current Fortemi React and Fortemi server importers accept the same archive.
  React-native SKOS and provenance component files remain available as an
  explicit option.
- **Metadata parity:** browser shard import/export now retains note metadata,
  allowing an AIWG shard to reconstruct the original index after a local
  archive round trip.

## Published Packages

- `@fortemi/core@2026.7.6`
- `@fortemi/graph@2026.7.6`
- `@fortemi/react@2026.7.6`

## Compatibility

This release is additive. Existing static AIWG index, Knowledge Shard, graph,
and React APIs remain compatible. Portable AIWG shard generation requires the
new `@fortemi/core/aiwg-index` converter.
