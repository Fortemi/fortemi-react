# fortemi-react v2026.6.2

fortemi-react v2026.6.2 is the graph-tooling release. It extracts the graph projection logic that lived inside the React `GraphView` into a new standalone, zero-dependency package, `@fortemi/graph`, so the same layout, filtering, coloring, and snapshot helpers can be shared by React apps and JS-only hosts. `@fortemi/core` is unchanged and remains the base layer.

## Highlights

- Added `@fortemi/graph`: framework-agnostic, zero-dependency helpers for graph layout, filtering, community color assignment, degree-based node sizing, bounds/fit calculations, neighborhood expansion, and static snapshot serialization. All helpers are pure and deterministic and operate on plain `CommunityGraph` data.
- Rewired `@fortemi/react`'s `GraphView` to delegate layout/filter/color/sizing to the add-on. Rendering behavior is unchanged; `useGraphController` now sources `GraphLayoutAlgorithm` from the package.
- Left `@fortemi/core` untouched as the base layer — it still owns graph production (`GraphRepository`, similarity/link graphs) and community detection. The dependency direction is strictly `react → graph` and `react → core`; core never depends on graph.
- Enabled JS-only hosts (e.g. static documentation sites) to render an AIWG relationship graph from a precomputed snapshot using these helpers, without React or PGlite. See `packages/graph/README.md` for a vanilla-JS SVG example.
- Extended CI to run the `@fortemi/graph` and `@fortemi/react` package test suites, and wired `@fortemi/graph` into the Gitea and npmjs.org publish workflows and the signed-tag release gate.

## Published Packages

- `@fortemi/core@2026.6.2`
- `@fortemi/graph@2026.6.2`
- `@fortemi/react@2026.6.2`

## Compatibility

Existing `2026.6.1` consumers can upgrade without source changes. The new `@fortemi/graph` package and its helpers are additive, and `GraphView` behavior is unchanged. Hosts that want the raw graph helpers directly can `pnpm add @fortemi/graph`. No archive schema migration is included in this release.

## Verification

Before cutting `v2026.6.2`, run the repository checks on the release-prep commit and wait for CI to pass:

```bash
pnpm typecheck
pnpm lint
pnpm test:core
pnpm test:e2e
pnpm build
```

Cut the release tag with the project release key only:

```bash
tools/release/cut-tag.sh 2026.6.2
git push origin main --tags
git push github main --tags
```
