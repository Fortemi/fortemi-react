# fortemi-react v2026.7.7

fortemi-react v2026.7.7 restores legacy Knowledge Shard compatibility in the
importer and adds end-to-end validation gates for the featured
knowledge-workspace demo.

## Highlights

- **Legacy shard compatibility (#344):** shard import accepts legacy React
  embedding rows that omit server metadata (`chunk_index`, `text`, `model`),
  normalizing them to schema defaults instead of rolling back the import.
  Legacy link, set-member, and embedding-set row shapes are equally accepted,
  and `validateShardArchive` now validates exactly what the importer accepts.
- **Demo semantic upgrade fixed:** the knowledge-workspace **Enable semantic
  search** flow imports the bundled `corpus.summaries.shard` successfully —
  no corpus rebuild required.
- **Bundled artifact conformance (#345):** the portable-contract CI gate now
  validates every checked-in corpus shard (schema, checksums) and replays the
  demo's exact three-shard import sequence into a freshly migrated database.
- **Browser smoke gate (#345):** a new `examples-e2e` CI job builds the
  deployable gallery and drives the featured demo end-to-end in Chromium —
  text search, semantic enablement, summaries import, query-model load, and a
  hybrid query with rendered results — failing on rollback banners or console
  errors.

## Compatibility

This release is backward-compatibility restoring and additive. Existing shard,
graph, and React APIs are unchanged. Shard archives exported by earlier
fortemi-react versions import cleanly again; server-exported shards are
unaffected.

`@bytecask/core` now resolves from public npmjs (2026.7.5). On npmjs.org this
release follows v2026.7.5 directly — v2026.7.6 was published to the internal
registry only, and its AIWG shard transport changes ship publicly here.
